# 약국 위치 안내 - GitHub Pages

## 업로드
`index.html`과 `pharmacy-map.png`를 GitHub 저장소의 같은 폴더(보통 root)에 올립니다.

GitHub → Settings → Pages → Deploy from a branch → `main` / `/ (root)` 선택.

생성된 GitHub Pages 주소를 QR 코드의 연결 주소로 사용하면 됩니다.

## 위쪽 3개 위치
- 천사약국: 위쪽 별표
- 솔약국: 왼쪽 별표
- 위드팜수약국: 오른쪽 별표

각 말풍선의 링크는 사용자가 제공한 네이버 지도 URL을 그대로 사용합니다.
